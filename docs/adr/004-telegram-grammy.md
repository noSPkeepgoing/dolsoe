# ADR-004: grammY 롱폴링 + 소유자 chat_id 단일 허용

- 날짜: 2026-09-30 · 상태: 채택됨

## 맥락
UI는 텔레그램뿐(초안 카드·인라인 버튼·링크 메시지). 공개 도메인·포트포워딩 불필요해야 함. REQ-007, REQ-014, EDGE-007.

## 결정
grammY 롱폴링. 모든 update는 미들웨어에서 `OWNER_CHAT_ID`(env)와 비교해 다르면 응답 없이 폐기. 처리한 `update_id`를 저장해 중복 콜백을 막는다. 콜백 데이터는 `BotCallbackSchema`로 경계 검증.

## 이유
jipsa에서 검증됨. 웹훅은 도메인·HTTPS 필요.

## 버린 대안
웹훅(공개 엔드포인트 필요), 다른 봇 라이브러리(학습 비용).

## 결과/트레이드오프
봇 토큰·chat_id는 `.env`(NFR-003).
