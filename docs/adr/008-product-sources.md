# ADR-008: 상품 소스 어댑터 — 도서=알라딘 API, 가전=링크 모드 우선(쿠팡 API 미확인)

- 날짜: 2026-09-30 · 상태: **부분 대체됨 — 도서 소스(알라딘)는 ADR-009로 교체**. 가전=링크 모드 우선 결정은 유효

## 맥락
PRD REQ-005·006, Q3(쿠팡파트너스 API 조건 미확인·신규 계정 제한 가능).

## 결정
`ProductSource` 인터페이스로 격리. 1차: `AladinSource`(베스트셀러·신간 → 책 큐레이션 B2), `CoupangLinkSource`(내가 준 쿠팡 링크에서 상품 정보 수집 → 가전 G1). 쿠팡 검색/베스트 API는 승인 조건 확인 후 `CoupangApiSource`로 추가(기본 모드에서 가전을 자동 선정). 그때까지 가전은 링크 모드로만 생성. 쿠팡 링크 스크래핑 가능 범위·약관은 build에서 확인(미확인) — 안 되면 사용자가 상품명·가격을 메모로 함께 주는 방식으로 축소.

## 이유
막힌 외부 API에 MVP를 걸지 않음. 소스만 교체 가능하게 격리.

## 버린 대안
쿠팡 API 전제 설계, 비공식 크롤링 상시 수집(약관 위험).

## 결과/트레이드오프
초기에는 하루 1편 중 가전 날은 사용자가 링크를 줘야 함(기본 모드가 가전을 못 만든 날은 REQ-005 규칙대로 건너뛰고 알림).
